# OAG RFC

Protocol definition for the infrastructuralization work: creating distributed foundational services for all being kind.

This repository is the evolving protocol and RFC home for the Open Agent Graph (OAG) infrastructure effort. It is intentionally a specification repository first. Implementations, experiments, and deployed services must remain distinguishable from the protocol proposals that describe them.

## Status

**Initial scaffold — proposed, not implemented.**

This repository currently defines the purpose, boundaries, and change process for the work. It does not claim that any service, network, governance mechanism, or interoperability guarantee described here is complete or deployed.

## Working principles

- Build open, inspectable, interoperable foundational services.
- Design for distributed operation rather than dependence on a single operator, vendor, or place.
- Preserve human and non-human agency, dignity, safety, and the ability to leave or fork.
- Label observed, implemented, documented, inferred, proposed, and unknown claims separately.
- Prefer reversible experiments and evidence over premature standardization.
- Treat the RFC process itself as part of the system under design.
